# rock-paper-scissors-odin
Rock Paper Scissors project for The Odin Project

Write a program that plays a game of rock paper scissors between a user and the computer. The game will play rounds whereby the users choice will be compared to the computers choice and points will be allotted to whomever wins each round. The game wins when either the user or the computer scores x amount of points.

The project does not have a user interface. it is played in te console and will only ask the user for an input

The project will receive prompts from the user of their chosen input: rock paper or scissors.

The desired output is a game of rock paper scissors where the users input is compared to the computers input and a point is given per round to the winner. The game plays as many rounds as needed until either the user or computer has a total of x points at which point the user is either declared the winner or loser
